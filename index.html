1 第一阶段：原型验证期（Flask Python 版）

项目立项 · 需求明确 起点
从教研实际痛点出发，明确核心需求：整卷拆分 + 分题型编辑 + Word导出。

2026-09-06 至 09-07

2 第二阶段：方案转型期（纯前端重构）
2026-09-08 上午
关键决策 · 转向纯前端方案 架构转型
发现 Flask 版存在两个致命问题：
① 教研同事不会装 Python 环境，使用门槛高
② Netlify 团队版 build 额度不足，不稳定
决策：重构成纯前端方案，用 docx.js 实现前端 Word 导出，GitHub Pages 免费部署。
2026-09-08 中午
纯前端版核心完成 + UI 重做
全部逻辑迁移至前端 JavaScript，零后端依赖。
UI 重新设计为清爽蓝白卡片式布局，1200px 居中两栏预览。
3 第三阶段：格式打磨期（v1.0 → v1.1）
2026-09-08 下午
新题型 bug 修复 迭代
用真实测试卷验收，发现并修复 2 个核心 bug：
① 选项重复：答案标记 [D] 混入选项列表 → 增加选项去重逻辑
② 引导段缺失：G 选项后段落被误吞 → 重写选项收集逻辑，以 41 题为边界

• 选项格式：支持 A. / [A] / A） 3 种
• 新增答案自动连写功能（失焦去空格去换行）
2026-09-08 下午
完形下划线格式三版迭代 迭代
经过三次调整，最终定版"带编号的下划线"格式：
v1 纯下划线 ____ → v2 数字两侧分开划线 → v3 数字+两侧空格整体加下划线
2026-09-08 下午
实时预览功能完善
HTML 预览从纯文本改为富文本渲染，下划线、加粗、选项排版所见即所得。
修复新题型题号下划线双重叠加问题（下划线字符 + CSS 下划线重复）。
4 第四阶段：月测模式扩展（v1.2）
2026-09-09
月测模式立项 新需求
月考试题结构与真题不同：语法 + 词汇双Part + 完形 + 翻译，共4大题。
需要新增独立模式，与真题模式平行。

月测全题型整卷导入
新增月测试题/答案解析识别器，支持：

• 词汇 Part1 词义替换（6-15）+ Part2 选词填空（16-25）
• 完形填空
• 翻译（46-50）
2026-09-09
词汇双 Part 上下布局 迭代
词汇题分 Part1 / Part2 两个子 tab 独立编辑，合并导出 Word。
各占独立大题编号，符合录题系统规范。
2026-09-10 上午
v1.2 月测模式全量验证通过 里程碑
整卷导入 → 分题型编辑 → 合并导出 Word 全链路打通。
7月月考样题自测全部正确，与9月大模考样题全量对照验证通过。
5 第五阶段：粘贴体验打磨（v1.2.1）
2026-09-10 上午
Word 粘贴下划线丢失 核心体验
问题：从 Word 复制到 textarea 时格式信息全部丢失。
方案：监听 paste 事件，解析 HTML 剪贴板，按字符追踪 underline/bold 格式，转换为 __/** 标记。
覆盖所有输入框：整卷导入4个 + 月测4题型 + 真题各题型。
2026-09-10 上午
粘贴乱码 & 标记叠加修复 迭代
问题1：Word HTML 含 style/XML 声明/条件注释被当文本 → 修复：递归 walk DOM 时跳过 style/script/head 等非内容节点
问题2：嵌套标签导致 ** 和 __ 叠加 → 修复：改用按字符格式追踪，每个字符只有一个 bold/underline 布尔值
2026-09-10 上午
Word 答案格式识别 迭代
问题：Word 中答案为 【答案】X 【解析】... 格式，原管道符格式解析失效。
修复：parseChoiceAnswersLocal 新增 Word 原生小节格式兼容（【答案】【解析】【题干翻译】等）。
2026-09-10 上午
镜像层方案废弃 技术决策
尝试透明 textarea + 格式化 div 实现 WYSIWYG 效果，但出现：
文字重影、底部重边框、对齐偏移、词汇题标记显示异常等大量 bug。
决策：稳定性优先，放弃镜像层，恢复纯 textarea + 右侧预览模式。
2026-09-10 上午
完形 & 选词填空下划线修复 迭代
选词填空：________ 空位连续下划线被 __(.+?)__ 正则误匹配 → 正则改为 __([^_]+?)__
完形空位：序号从 1 开始重排 + 仅识别 __数字__ 标记格式，避免年份等普通数字误判
2026-09-10 上午
完形粘贴自动拆分选项 新功能
从 Word 复制完形全文（文章 + 选项连写/分行）时自动拆分：
文章留当前输入框，选项自动填入下方选项框。
支持换行格式和连写格式两种模式。
2026-09-10 上午
月测翻译格式对齐 迭代
标签从【解答题】统一为【复合题】。
新增 Word 答案解析合并格式支持：数字.【答案】...【解析】...，粘贴后自动拆分答案和解析。
2026-09-10 中午
v1.2.1 上线 上线
Word 粘贴全链路打通 + 完形/选词填空修复 + 月测格式对齐 + 自动拆分选项。
6 第六阶段：拆分体验优化（v1.2.2）
2026-09-11 上午
答案智能断句独立化 架构
问题：从Word粘贴的答案解析为全连写状态，整卷拆分后答案匹配为空。
方案：新增独立的 smartFixAnswerLineBreaks 函数，与试题断句逻辑完全分离。
针对答案特征（【答案】【解析】【试题解析】【参考译文】【参考范文】等）精准断句，避免误拆解析正文。
2026-09-11 上午
试题断句能力全面增强 迭代
修复4项关键断句缺陷：
① Unicode罗马数字（Ⅰ/Ⅱ/Ⅲ/Ⅳ）无法识别 → 支持4种数字写法
② \b 词边界对Unicode字符失效 → 改用前瞻断言
③ 阅读题干行句号后有空格时匹配失效 → 增加弹性空格匹配
④ 句号后紧跟题号未换行 → 新增"句末标点+两位数题号"规则
2026-09-11 上午
阅读 Part A 批量导入 功能
真题整卷拆分暂时下线，改为阅读 Part A 独立批量导入。
粘贴整套 Text 1-4 一键拆分，自动填入4个Text编辑框，可选答案解析按题号匹配。
支持Word连写粘贴（自动智能断句），不影响已有数据。
2026-09-11 上午
阅读选项格式全兼容 迭代
问题：parseReadingQuestions 仅支持 A. 格式，真题方括号 [A] 选项识别失效。
修复：新增 [A] / A. / (A) 三种格式支持，
同时兼容"选项跟题干同一行"的连写格式。
2026-09-11 上午
完形粘贴拆分强化 迭代
① 纯文本粘贴也触发自动拆分（此前仅富文本粘贴触发）
② 拆分前先执行智能断句，从Word连写粘贴的完形全文也能正确拆开
2026-09-11 上午
v1.2.2 完成 里程碑
答案断句独立化 + 阅读批量导入 + 选项格式全兼容 + 粘贴体验全面优化。
